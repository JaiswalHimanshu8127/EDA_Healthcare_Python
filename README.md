#EDA_Healthcare_Python

📖 Project Overview

This project performs Exploratory Data Analysis (EDA) on a healthcare claims dataset to understand claim patterns, cost distribution, and key factors influencing claim amounts. The goal is to derive actionable insights that can support healthcare insurance decision-making and cost optimization.

🎯 Business Objective

Analyze healthcare claim amounts and trends

Identify high-cost claim categories and patient segments

Detect potential anomalies or outliers in claims data

Support better claim management and policy decisions

📂 Dataset

Type: Healthcare Claims Dataset

Records: Multiple claim entries

Key Columns:

Patient Age

Gender

Diagnosis / Procedure

Claim Amount

Claim Date

(Dataset used for analytical and learning purposes)

🛠 Tools & Technologies Used

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

🔍 Steps Performed

Imported and explored dataset structure

Handled missing values and duplicates

Corrected data types and cleaned inconsistent values

Performed univariate and bivariate analysis

Detected outliers using statistical techniques

Visualized trends and distributions

📊 Key Insights

Certain age groups show significantly higher average claim amounts

A small percentage of claims contribute to a large portion of total cost

Outliers indicate potential high-risk or abnormal claims

Claim amount distribution is right-skewed

📈 Visualizations Used

Bar charts

Histograms

Box plots

Count plots

✅ Conclusion

The analysis provides meaningful insights into healthcare claim behavior and cost drivers. These insights can help insurers improve claim monitoring, identify risk patterns, and optimize operational strategies.
